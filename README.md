# ⚡ ClipForge

### Your clipboard. Your history. Your control.

**ClipForge** is a modern clipboard history manager for Windows, built with Electron and JavaScript.

Ever copied something important, copied something else, and lost the first item? ClipForge keeps track of your copied text so you can search, retrieve, and reuse previous entries without interrupting your workflow.

> Copy more. Search less. Stay focused.

---

## ✨ Features

- **📋 Clipboard History** — Automatically tracks copied text.
- **🔎 Instant Search** — Find previous clipboard entries quickly.
- **📌 Pinned Items** — Keep important entries close at hand.
- **⚡ Quick Copy** — Copy any saved entry back to your clipboard.
- **⌨️ Global Shortcut** — Open ClipForge with `Ctrl + Shift + V`.
- **⏸️ Pause Tracking** — Temporarily stop collecting new entries.
- **🗑️ History Management** — Delete individual entries or clear your history.
- **💾 Local Storage** — Save clipboard history locally on your device.
- **🌙 Modern Dark UI** — A clean interface designed for everyday productivity.

## 🚀 Installation

### Download the Latest Release

1. Visit the [ClipForge Releases](https://github.com/Itz-Veyn-Dev/ClipForge/releases) page.
2. Download the latest Windows installer (`ClipForge Setup .exe`).
3. Run the installer and follow the on-screen instructions.
4. Launch ClipForge and start building your clipboard history!

### Run from Source

**Requirements**
- Windows
- [Node.js](https://nodejs.org/) and npm

Clone the repository:

```bash
git clone https://github.com/Itz-Veyn-Dev/ClipForge.git
cd ClipForge
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

### Build the Windows Installer

```bash
npm run dist
```

Build output will be generated in the `release` directory.

## 🔒 Privacy

ClipForge stores clipboard history locally on your device and does not require an online account or cloud storage.

**Important:** Clipboard managers may collect sensitive text you copy. Avoid copying sensitive information while tracking is active, pause tracking when appropriate, and clear entries you no longer need.
